# Horsteppe — ознакомительный сайт

Сайт для клиентов Horsteppe на трёх языках (English · Русский · Қазақша) с записью на ранний доступ
и закрытой админкой, где видны все заявки.

| Адрес | Что там |
|---|---|
| `/en` · `/ru` · `/kk` | Сайт: что такое Horsteppe, как работает, возможности, для кого, ранний доступ, вопросы |
| `/{язык}/privacy` | Как обрабатываются данные из формы |
| `/admin` | Админка заявок (вход по паролю): поиск, фильтры, статусы, заметки, CSV, Google Таблица |

Язык выбирается по браузеру и запоминается. Сайт работает без JavaScript — кроме формы и админки.

## Как устроено

- **Next.js 15 + React 19 + Tailwind 4** — тот же стек и фирменный стиль, что у продукта.
- **Заявки** — таблица `intro_leads` в Supabase проекта Horsteppe ([supabase/intro_leads.sql](supabase/intro_leads.sql)).
  Таблицы закрыты для браузера; пишет и читает только сервер сайта.
- **Форма:** проверка полей, ловушка для ботов, лимит частоты (5 заявок в час с адреса, 300 в час всего),
  склейка повторных заявок по email, страна и город по IP (сам IP не хранится).
- **Админка:** пароль из `ADMIN_PASSWORD`, подписанная cookie на 12 часов, лимит неудачных входов,
  защита от CSRF. Статусы: новая → связались → пригласили → клиент / отказ. Заметки команды.
  Удаление по просьбе человека.
- **Google Таблица:** в админке — формула `=IMPORTDATA(...)` с секретной ссылкой; таблица обновляется сама.
- **Telegram:** если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, каждая заявка приходит сообщением.

Подробности и решения — [docs/BRIEF.md](docs/BRIEF.md). Запуск на проде — [docs/DEPLOY.md](docs/DEPLOY.md).

## Разработка

```bash
npm install
npm run dev          # http://localhost:3000 — без ключей заявки пишутся в .data/
npm test             # логика: заявка, CSV, сессия, лимиты, хранилища
npm run build
npm run qa           # Chrome без окна: 3 языка × телефон и ноутбук, форма, админка, скриншоты в qa-output/
```
