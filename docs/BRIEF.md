# BRIEF: ознакомительный сайт Horsteppe и админка заявок

**Дата:** 2026-11-03 · **Заказчик:** основатель Horsteppe · **Исполнитель:** AI-агент.

## Зачем

У Horsteppe 10+ клиентов, бесплатные работы прекращены, желающих становится больше. Нужен
отдельный ознакомительный сайт: всё о продукте для клиентов, три языка (en / ru / kk) и запись на
ранний доступ. Отдельно — админка, где основатель (или человек с паролем) видит всех записавшихся.

## Что строим

1. **Публичный сайт** `/{en|ru|kk}` — одна длинная страница: обложка, чем Horsteppe отличается от
   генераторов клипов, как это работает, возможности, для кого, ранний доступ (форма), вопросы.
   Плюс `/{lang}/privacy` — как обрабатываются данные из формы.
2. **Форма раннего доступа** → `POST /api/lead` → таблица `intro_leads` в Supabase проекта Horsteppe.
3. **Админка** `/admin` (только русский, закрыта от поиска) — вход по паролю, заявки с поиском и
   фильтрами, статусы и заметки (мини-CRM), удаление по просьбе человека, выгрузка CSV и живая
   Google-таблица через `=IMPORTDATA(...)`.
4. **Уведомление в Telegram** о каждой новой заявке — если задан бот.

## Правила, которые не нарушаем

- **Правда в текстах.** Только то, что продукт реально делает (см. код `Horsteppe/worker` и
  `Horsteppe/web`). Нельзя: «полные авторские права» (PROVIDERS_LEGAL §3), выдуманные цены, отзывы,
  логотипы клиентов, обещания сроков. Казахский — машинный перевод, ждёт вычитки носителем.
- **Ни одна заявка не теряется молча.** Нет базы — форма честно говорит «временно недоступна» и
  даёт почту; успех показывается только после записи.
- **Секреты только на сервере.** Ключ Supabase и пароль админки живут в переменных окружения
  Vercel; в браузер не попадают; в git нет `.env`.
- **Защита формы:** проверка полей, скрытое поле-ловушка, минимальное время заполнения, лимит
  частоты по хешу IP (сам IP не хранится), дедупликация по email.
- **Защита админки:** пароль сравнивается за постоянное время, сессия — подписанная cookie
  (HttpOnly, SameSite), лимит неудачных входов, защита от CSRF по Origin, `noindex`.
- **CSV без формул:** значения, начинающиеся с `= + - @`, экранируются — заявка не может
  подложить формулу в таблицу основателя.
- **Без лишнего:** никаких трекеров, баннеров, чатов. Быстрая статика, работает без JavaScript
  везде, кроме формы и админки.

## Стек

Тот же, что у продукта, — уже принят Vercel и проверен сборкой: Next.js 15.5.25, React 19.1.1,
Tailwind 4.3.3, TypeScript 5.9.3. Фирменный стиль — палитра «степь» и шрифты Montserrat + Inter из
`Horsteppe/web`. Хранилище — Supabase (тот же проект, отдельные таблицы `intro_*`). Локально без
ключей — файловое хранилище `.data/` для разработки и тестов; на проде оно выключено.

## Как проверяем

- `npm test` — логика без сети: проверка заявки, CSV, сессия, лимиты, хранилища (Supabase — на
  подменённом fetch: форма запросов к PostgREST).
- `npm run build` + проверка типов.
- `npm run qa` — Chrome без окна: три языка × телефон и ноутбук, ошибки консоли, горизонтальная
  прокрутка, отправка формы, вход в админку, смена статуса, CSV, ссылка для Google Таблиц.
- Скриншоты каждой страницы — смотрим глазами.
