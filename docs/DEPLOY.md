# ЗАПУСК: что сделать руками

Всё остальное уже готово и проверено. Здесь — только шаги, для которых нужен ваш доступ.

## Шаг 1. Таблицы в Supabase (1 минута)

1. Supabase → ваш проект Horsteppe → **SQL Editor** → **New query**.
2. Вставьте целиком файл [supabase/intro_leads.sql](../supabase/intro_leads.sql) → **Run**.
3. Должно появиться «Success. No rows returned». Повторный запуск безопасен.

Данные продукта (ролики, проекты) это не затрагивает: создаются две новые таблицы `intro_*`.

## Шаг 2. Сайт на Vercel (3 минуты)

1. vercel.com → **Add New… → Project** → **Import** репозитория `Horsteppe-introductory-website`.
2. Перед нажатием **Deploy** откройте **Environment Variables** и добавьте три переменные:

| Имя | Где взять |
|---|---|
| `SUPABASE_URL` | Supabase → Project Settings → Data API → **Project URL** (или из настроек проекта `horsteppe` в Vercel: `NEXT_PUBLIC_SUPABASE_URL`) |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase → Project Settings → API Keys → **service_role** (или из проекта `horsteppe` в Vercel) |
| `ADMIN_PASSWORD` | Придумайте сами: не короче 8 символов, лучше 12+. Это пароль входа в `/admin` |

3. **Deploy**. Через минуту сайт откроется по адресу вида `horsteppe-introductory-website.vercel.app`.

## Шаг 3. Проверка (2 минуты)

1. Откройте сайт, оставьте заявку на себя — должно появиться «Заявка принята».
2. Откройте `/admin`, введите пароль — ваша заявка будет в списке.
3. Кнопка **Google Таблица** → скопируйте формулу → вставьте в A1 новой таблицы на sheets.google.com.

Если вместо подтверждения форма пишет «Запись временно недоступна» — не применён шаг 1 или неверны
переменные шага 2. Заявки при этом не теряются молча: человек видит почту для связи.

## Telegram-бот заявок (5 минут)

Бот сразу пишет о каждой новой заявке («🆕 Новая заявка на ранний доступ» — имя, почта, контакт,
задача) и показывает все заявки прямо в Telegram.

1. **Создайте бота.** В Telegram откройте [@BotFather](https://t.me/BotFather) → отправьте `/newbot` →
   придумайте название (например, «Horsteppe Заявки») и адрес, который кончается на `bot`. BotFather
   пришлёт токен — длинную строку вида `123456789:AAH…`. Скопируйте её.
2. **Отдайте токен сайту.** Vercel → проект → Settings → Environment Variables → добавьте
   `TELEGRAM_BOT_TOKEN` = токен → Save. Затем Deployments → «…» у последнего → **Redeploy**.
3. **Обновите базу.** Supabase → SQL Editor → вставьте весь файл
   [supabase/intro_leads.sql](../supabase/intro_leads.sql) → Run. Повторный запуск безопасен: добавится
   только таблица для бота.
4. **Подключите свой Telegram.** Админка сайта → кнопка **Telegram** → **Подключить Telegram** →
   **Открыть бота в Telegram** → в Telegram нажмите **Start**. Готово — бот пришлёт приветствие.

**Что умеет бот.** Кнопки внизу чата: «🆕 Новые» (ждут ответа), «📋 Все заявки», «📊 Статистика».
Под каждой заявкой — кнопки статуса «Связались», «Пригласили», «Клиент», «Отказ»; статус меняется и в
админке. Ответьте на заявку текстом — сохранится заметкой. Напишите имя, почту или компанию — бот
найдёт заявку. `/stop` — больше не присылать в этот чат.

**Ещё люди и группа.** Второго человека подключают той же кнопкой в админке: ссылку открывают на его
телефоне. Общая группа команды — ссылка «Добавить бота в группу». Список подключённых и кнопка
«Отключить» — там же, в окне Telegram в админке.

**Если бота найдёт клиент.** Он не увидит ни одной заявки: доступ к ним только у чатов, подключённых по
ссылке из админки (она живёт 30 минут). Клиенту бот ответит на его языке (русский, казахский,
английский): где заказать видео — ссылка на заявку на сайте — и что для вопросов и связи с
основателями можно написать в Telegram @horsteppe. В меню бота клиент видит только «Заказать видео и
связаться с командой»; рабочие команды видны лишь в ваших подключённых чатах. Описание бота для
клиентов ставится само, когда в админке нажимают «Подключить Telegram».

## По желанию

- **Свой домен.** Vercel → Settings → Domains. Затем переменная `NEXT_PUBLIC_SITE_URL=https://ваш-домен`.
- **Дать доступ к админке другому человеку** — сообщите ему пароль. Отозвать — смените `ADMIN_PASSWORD`
  в Vercel и нажмите Redeploy: все сессии и ссылка Google Таблицы перестанут работать.

## Перед рекламой — проверить с юристом

- **Хранение персональных данных граждан РК.** Закон РК «О персональных данных и их защите» требует
  хранить такие данные в базе на территории Казахстана. Supabase и Vercel — зарубежные. Это
  нужно решить до массового сбора заявок.
- **Тексты на казахском** переведены машинно — их нужно вычитать носителем языка.
- Формулировка о правах на ролик взята из `Horsteppe/docs/PROVIDERS_LEGAL.md §3`.
